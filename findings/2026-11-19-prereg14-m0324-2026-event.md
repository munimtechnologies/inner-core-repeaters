## Why this event matters

Multiplet M03-24 (Z004 in this repo) is a family of repeating South Sandwich Islands
earthquakes. At the Yellowknife array (YKA, Canada), the late PKIKP coda (3-10 s after
onset, 1-2 Hz beams; column `D_c310` of `results/m0324chk-v2/yka_z004_pairs.csv`) splits the
eight usable members into two groups:

* **X** = 2003-03-21, 2020-07-11, 2022-03-07, 2024-03-21, 2025-12-13
* **Y** = 2008-02-17, 2011-02-20, 2014-12-09
* 2022-10-15 (SNR 6) is left out, as before.

Published values (D = 1 - correlation): within X 0.0012-0.0228 (10 pairs), within Y
0.018-0.033 (3 pairs), between groups 0.098-0.156 (15 pairs). The split was found
exploratorily (findings/2026-11-18-m0324chk-v2-results.md). The pre-registered mantle-P
control (pre-registration 11, findings/2026-11-18-mantlep2-results.md) found no such split in
mantle P at 7 independent stations (decision N), so the change lies on the path through the
core, not at the source.

USGS ComCat now lists **us7000ty3q**, 2026-11-13 19:04:07.7 UTC, 58.962°S 25.725°W, depth
63.8 km, mb 5.1 (horizontal error 12 km). That lies inside the catalogue footprint of M03-24
(members at 58.98-59.09°S, 25.47-25.86°W). It happened six days ago, so no published study can
have used it. If it is a true repeat, it is the first event of this family that was never
part of any analysis. The family split was found in data we had already seen; this event
tests it out of sample.

## What each picture predicts

* **Backtracking** (Wang, Vidale et al. 2024, *Nature*): the turn was at 2008.5 and the
  backward motion is 2.5 times slower, so 2026.868 maps to an effective 2001.15. Group X spans
  effective 2001.5-2003.7, so the new event should look like **X**. On that clock the closest
  X member is 2025-12-13 (0.37 yr apart in effective time), then 2024, 2022-03, 2003 and 2020.
* **Surface change with quiescence** (Zhang & Wen 2026, *JGR*: episodic change, quiescence,
  recovery): if the inner-core surface stays quiet after its recovery, **X**. A new episode
  would give a state that matches neither group.
* **Rotation that matches the mantle's since about 2010, with no surface change** (Wu, Song & Yang
  2026, *GRL*): waveforms after 2010 should look like 2011-2014, so **Y**. The X/Y split already
  disagrees with this for 2020-2025, so we do not expect it.

The test cannot tell backtracking from quiescence when the answer is X. Its value is that
it is out of sample: **Y or a new state, from a verified repeat, would mean the
inner-core path changed between December 2025 and November 2026**. Nobody has reported that.

## Method (code: `m26.py` 0.1.0, compete job `icr-m26-v1`)

**Part M, source check (P14-0).** `mantlep2.py` v0.13.0 (pinned commit b4712f0e) is run
unchanged, with only the new event appended to its event list. It covers the eight stations
of pre-registration 13: IU.QSPA, GT.VNDA, IU.LCO, GT.DBIC, GT.PLCA, GT.LPAZ, GT.LBTB and
IU.LSZ (1-2 Hz, mantlep2's alignment and gates: direct SNR >= 5, late SNR >= 2, `D_late`
3-10 s after the aligned onset). A station counts if the new event is gated and at least 5
of the 8 old events are gated. At each counted station, each gated event gets m = the median
`D_late` to the other gated events (old and new). The score is q = the share of old events
whose m is below the new event's m. Under a common source, q is roughly uniform on 0-1. Under
a different source (or different depth, since pP and sP fall in the window), q is 1.

* **same** if the median q over counted stations is <= 0.75; **different** if it is >= 0.999;
  **inconclusive** otherwise; **untestable** if fewer than 3 stations count.

**Part Y, core state (P14-1, primary).** `m0324_check.run_yka` (v0.8.0, pinned) is run with
`yka_repick`'s ±2 s onset picker, exactly as in icr-m0324chk-v2, on the nine Z004 events plus
us7000ty3q. Pair quality gates are unchanged (reference cc >= 0.90, direct SNR >= 5, coda SNR
>= 2; these act as the membership test at YKA). From the ok pairs that include the new event,
dX = median `D_c310` to the X members and dY = median `D_c310` to the Y members.

* **untestable** if fewer than 3 X or fewer than 2 Y partners are ok;
* **X** if dX <= 0.05 and dY >= 0.07 and dY >= 3 dX;
* **Y** if dY <= 0.05 and dX >= 0.07 and dX >= 3 dY;
* **new-state** if both dX and dY are > 0.05;
* **ambiguous** otherwise.

**Headline.** **X-confirmed** if the source is same and the state is X. **change-detected**
if the source is same and the state is Y or new-state. **not-a-repeat** if the source is
different. **source-unverified:<state>** if the source is inconclusive or untestable.
**untestable** if P14-1 is untestable.

**Secondaries (reported, not decisive).**
* S14 ungated: the same labels using all pairs, ignoring the gates. Also the 1-6 s coda `D`
  and `D_c13` to each partner.
* S14a, backtracking order: the Spearman correlation between `D_c310`(new, x) and the
  effective-time distance |equiv(new) - equiv(x)| over the ok X partners. Backtracking predicts
  rho > 0. This is weak: the existing pattern (2022-03, 2024 and 2025-12 nearly identical,
  0.0012-0.0018) already puts the latest members closest, so we expect rho > 0 under most
  pictures.
* S14b, exploratory extra run: us6000thwz (2026-08-04, mb 4.5, 58.920°S 25.596°W, depth
  fixed at 35 km) is added as well. It is small and may fail the gates. Its label is
  reported, never used in the headline.
* R14, reproduction: run "old9" (no new event) must reproduce the published YKA values
  (max |ΔD|, |ΔD_c310| < 0.001). The primary run may differ slightly, because adding an event
  can change the reference event and the stack onset. Both differences are reported. The
  mantle-P D_late of old pairs is compared with `results/mantlep2-v1/mantlep2_pairs.csv`.

## What happens next

* If the YKA data for the new event are not yet in the archives (EarthScope or NRCan), the
  result is untestable *for now*. The same code will be re-run unchanged under a new job
  version until the data are there. Nothing in this file changes.
* If the result is **change-detected**, it is checked before anyone is told: the per-station
  plots, the mantle-P plots, ILAR (by a separate pre-registration), and whether the new
  event's YKA hardware or element set differs from 2014-2025. Only then is it published as a
  result.
* Further 2026-2027 events in the footprint will be tested the same way, each before its
  waveforms are looked at.

## Limits written in advance

* One event, one array (YKA) for the core state. ILAR is not used here.
* The thresholds are set from the published spread of D_c310, which is the same data in
  which the split was found. Only the new event is out of sample.
* Membership rests on the YKA quality gates and on the mantle-P score at no more than 8 stations.
  ComCat depth (63.8 km) and location are poorly resolved for an mb 5.1 event.
* An X result cannot tell backtracking from a quiet inner-core surface.
