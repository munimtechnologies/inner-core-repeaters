# Pre-registration: is the 2025-12-13 M03-24 anomaly real? (`m0324_check.py`, v0.8.0)

MV2, Munim, Inc. (made with AI agents). Written 2026-11-17, after reading the
icr-m0324-v1 results ([`2026-11-17-m0324-results.md`](2026-11-17-m0324-results.md)) and
**before** any of the checks below was run. No YKA waveform of these nine events has been
looked at by this project. The YKA stage A run (`icr-yka-v1`, all SSI events M ≥ 5.0 /
4.7) was running when this was written, and none of its output had been read. Text CC BY 4.0.

## What is being checked

In multiplet M03-24 (our Z004, nine events 2003-2025) at ILAR, the 2025-12-13 event
(us6000runq) has PKIKP dissimilarity D = 0.167 to the 2003-03-21 event and D = 0.033 to
the 2011-02-20 event. The backtracking model (Wang et al. 2024) predicts the reverse. This
is one event at DF SNR 3.2, so it needs checking before anyone reads anything into it. The
anomaly is written A > B, with

* A = D(2003-03-21, 2025-12-13), and
* B = D(2011-02-20, 2025-12-13).

## Checks and decision rules (fixed)

**R0, reproduction.** From the ILAR beams cached by icr-m0324-v1, recompute all 36 Z004
D values with the same alignment, onset and windows. This holds if the largest absolute
difference from the published values is under 0.001. If R0 fails, C1 and C2 are reported
but not interpreted.

**C1, element bootstrap at ILAR.** Rebuild each event's beam from the 1-2 Hz
static-corrected elements cached by icr-m0324-v1, keeping only elements common to all nine
events. Run 500 bootstrap resamples of elements, with replacement and the same resample
for every event, plus every leave-one-element-out case. Alignment offsets and windows are
held at their R0 values. The anomaly is **robust at ILAR** if A > B in ≥ 95% of bootstrap
replicates **and** in every leave-one-out case.

**C2, PKIKP window.** Recompute A and B with three other windows relative to the picked
onset:

* early: −0.3 to 1.2 s;
* late: 1.0 to 2.5 s;
* long, DF plus coda up to just before the reference window: −0.3 to 6.0 s.

**Window-robust** if A > B in all three.

**Y1, second array (YKA, Canada).** Download YKA (network CN) records of the nine Z004
events. Process them with the published `yka.py` v0.2.0, unchanged and fetched at commit
314a42d, using its pre-registered metric: align on the direct PKIKP pulse (−0.3 to
0.9 s), then D = 1 − cc of the PKIKP coda (+1 to +6 s). Its quality gate is direct-pulse
cc ≥ 0.90, direct SNR ≥ 5 and coda SNR ≥ 2.

* **Testable** if both the (2003, 2025-12-13) and (2011, 2025-12-13) pairs pass the gate.
* **Replicated** if A > B at YKA.
* **Contradicted** if A < B.

Ungated values are always reported, and labelled as ungated.

**Y0, YKA in-sample pattern.** Testable if the YKA pairs (2003, 2011), (2003, 2020) and
(2003, 2024) all pass the gate. Holds if D(2003, 2011) > max(D(2003, 2020), D(2003, 2024)).
This is the pre-2025 split seen at ILAR, and in Wang et al.'s by-eye YKA grades.

## How the outcome will be described

* **R0 + C1 + C2 all hold:** "a robust ILAR observation, from one event." It will not be
  called a refutation of backtracking.
* **Y1 replicated as well:** "seen on two independent arrays." The next step is then
  author contact (sent for review first) and a dedicated look at every 2026 event of the
  patch.
* **C1 or C2 fails:** the anomaly is reported as not robust, and the M03-24 thread goes
  back to waiting for more and stronger new events.
* **Either way:** the whole-arc forecast-date scan (`fdscan.py`, pre-registered
  separately) remains the main test of the 2024 model.

## Forecasts (written before running)

* R0 holds: **90%**.
* C1 robust: **55%**.
* C2 window-robust: **50%**.
* Y1 testable: **25%**. The 2003 event is mb 4.8, and its direct pulse at YKA, about
  135° away, may be under SNR 5. If testable, replicated: **50%**.
* Y0 testable: **30%**. If testable, holds: **65%**.

## Honest limits

* C1 resamples only the stations. It does not capture errors in the event-level alignment,
  the onset pick, or source differences between the repeaters.
* YKA measures coda similarity, not the DF pulse itself. It samples a different part of the
  inner core (the path to Canada, not Alaska), so agreement is supporting evidence, not a
  replication of the same ray.
* The 2003-2014 YKA records come from the legacy YKB/YKR elements; 2014-2025 from the current
  YKAB/YKAR elements (different digitisers). A and B both pair a legacy event with the
  current-era 2025 event, so this affects both equally.
