# Pre-registration 13: which clock do source-verified repeaters follow?

By MV2, Munim, Inc. (made with AI agents). Written 2026-11-18 (about 20:00 UTC), before
`mantlep3.py` fetched any waveform. Text CC BY 4.0; code Apache-2.0. No human expert has
reviewed this plan.

## The question

Is Earth's inner core turning back ("backtracking")? Or does its surface change in place
without any rotation? Wang, Vidale et al. (2024, *Nature* 631:340) read changes in repeating
South Sandwich Islands (SSI) earthquakes as an inner core that reversed around 2008.5 and moves
back about 2.5 times more slowly. Zhang & Wen (2026, *JGR Solid Earth*,
doi:10.1029/2026JB034595) read the same kind of record (one multiplet, M03-24) as episodic
changes of the inner-core surface, with no rotation.

The two readings make different predictions about **time**:

* **B (backtracking clock).** Rotation moves every path on one timeline. Two events should
  look alike through the inner core when the core was in the same position:
  dB = |e(t1) − e(t2)|, with e(t) = t before 2008.5 and 2008.5 − (t − 2008.5)/2.5 after.
* **M (monotone clock).** Steady rotation, or slow monotone change: alike when close in time,
  dM = |t1 − t2|.
* **None.** Local surface changes at arbitrary epochs need not follow either clock across
  families tens of kilometres apart.

Our earlier lanes could not answer this because of the **source**. At Yellowknife (YKA),
the coda difference between catalogue "repeaters" grows with how far apart their sources are
and not with time (diag-v1: Spearman ρ with source separation 0.27, with time 0.01, 1,650
pairs). In the one family where we checked the source directly, M03-24, mantle P (which never
enters the core) showed the sources are alike, while the core-path coda changed and changed
back (pre-registration 11, decision N). This test applies that source control to **every
published pair**, then asks which clock the core change follows **among pairs whose sources
are verified alike**.

## What has and has not been seen

* **Seen:** the core-side pair tables used here are public and were analysed before:
  `results/ykab-v2/yka_pairs.csv` (YKA stage B, 1,650 ok pairs; diag-v1 computed their
  dependence on time, separation, SNR and magnitude, and a near/far-in-time contrast; it did
  **not** compute ρ with dB) and `results/ilar-v1/pairs.csv` (ILAR, 136 ok pairs; the v0.7
  result ρ_B = 0.19 vs ρ_M = 0.07 used all of them). The M03-24 events' mantle P at the eight
  stations below was seen in mantlep2-v1.
* **Not seen:** mantle P of every other event at every station. The source score S, and so
  the set of verified pairs, is unknown at the time of writing. Every decision below depends
  on S.

## Data and measurement (`mantlep3.py` 0.15.0, run as compete job `icr-h13-v1`)

1. **Pairs.** Rows with ok = True of the YKA table (commit f65c966a) and the ILAR table
   (commit 7067d4fc), fetched from this repository at those commits. Both clocks are
   recomputed from t1, t2. Locations: USGS ComCat (same query as `icrdiag.py`), matched by id,
   else by origin time within 5 s; depth 33 km if missing.
2. **Stations.** The eight stations usable in mantlep2-v1: IU.QSPA, GT.VNDA, IU.LCO, GT.DBIC,
   GT.PLCA, GT.LPAZ, GT.LBTB, IU.LSZ (BHZ). Fixed before any new data.
3. **Per family, per station:** mantlep2's method unchanged (1-2 Hz velocity, reference = event
   with the best raw SNR, anchor at 25% envelope within −5..+15 s of ak135 P, envelope then
   waveform alignment on the P train, stack onset, gates: direct peak SNR ≥ 5 and late RMS
   SNR ≥ 2). New: a family-station is discarded if the reference onset lies within 0.25 s of
   the start of the search window (the noise signature found in mantlep2-v1). For each needed
   pair with both events gated: D_late = 1 − cc over 3-10 s after the onset (this window holds
   pP and sP, so it is sensitive to depth and location differences).
4. **Source score.** At each station with ≥ 20 gated pairs, each pair's D_late is converted to
   its percentile among all gated pairs at that station (rank/n). S = median percentile over
   stations; a pair is scored if it has ≥ 2 stations. Low S = sources alike.

## Tests and decision rules

All statistics exclude pairs with both events in M03-24 (already used); including them is a
sensitivity check. Bootstraps resample whole families (1,000 draws, fixed seeds).

**P13-0 Calibration (must pass for the clock test to be read).** On scored YKA pairs:
ρ(S, core D) ≥ 0.15 and its family-bootstrap 5th percentile > 0. If source similarity, as
measured by mantle P, does not predict core similarity, S is not measuring the source
differences that matter, and the decision is **untestable-calibration** (the clock statistics
are still reported, labelled exploratory).

**P13-1 Clock (primary).** Verified pairs V = scored YKA pairs with S ≤ 1/3. Core metric:
YKA stage-B D (the PKIKP coda measure that stage B pre-registered). Testable if |V| ≥ 40,
≥ 4 families and ≥ 10 pairs that straddle 2008.5 (only these separate the clocks).
ρ_B = Spearman(D, dB) and ρ_M = Spearman(D, dM) on V.

* **B** if ρ_B ≥ 0.10 and ρ_B > ρ_M in ≥ 90% of bootstraps;
* else **M** if ρ_M ≥ 0.10 and ρ_M > ρ_B in ≥ 90%;
* else **none** if both ρ < 0.10 and both bootstrap 95th percentiles < 0.20;
* else **inconclusive**.

**Secondary (reported, not the decision):** the same on ILAR pairs (ILAR D); on YKA D_c310
(late 3-10 s coda); sensitivity with S ≤ 0.25, S ≤ 0.5, D_c13, and with M03-24 included.
Diagnostic: ρ(core D, catalogue separation) on scored vs verified pairs (if S works, it should
drop in V).

## What each outcome would mean

* **B:** among earthquake pairs whose sources are shown to be alike, inner-core change follows
  the backtracking timeline across many families. That would be the first source-controlled,
  multi-family support for the 2024 reversal, independent of by-eye grading.
* **M:** change accumulates with time, as in steady differential rotation or slow growth, not
  a reversal.
* **none:** with the source removed, the change follows no global clock, which favours local
  changes of the inner-core surface (or no resolvable change at these magnitudes).
* **untestable / inconclusive:** the catalogue families are too small or noisy at M4.3-5.3.

## Forecasts (made before any data)

* At least 5 of 8 stations reach ≥ 20 gated pairs: 65%.
* P13-0 passes: 55%.
* P13-1 testable: 50%.
* Given testable: B 25%, M 15%, none 35%, inconclusive 25%.
* Overall most likely single outcome: untestable (calibration or too few verified pairs).

## Limits written in advance

* Mantle P leaves the source at 15-40° from vertical; PKIKP leaves almost straight down. A
  change confined to a narrow cone below the source would not show in S.
* The core-side tables were analysed before (see above); only S is new.
* S is relative (percentiles), so "verified" means "among the most alike third at these
  stations", not identical.
* Families are catalogue-based and differ in size; the family bootstrap is the guard against
  one big family deciding the result.
